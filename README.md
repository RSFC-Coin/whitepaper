## What is RFSC?

**RFSC Coin** is a decentralized cryptocurrency project designed to combine
digital scarcity, peer-to-peer decentralization, useful computational work,
transaction privacy, smart contracts, and high-performance blockchain
infrastructure.

RFSC is designed as an independent blockchain network rather than a token
that depends on an existing blockchain.

The project introduces a **Proof of Useful Work (PoUW)** concept where mining
computation can be used for useful computational workloads, including
AI model training.

---

## Core Features

- **Fixed Maximum Supply** — 21,000,000 RFSC
- **Decentralized P2P Network**
- **Proof of Useful Work (PoUW)**
- **AI Model Training Mining**
- **UTXO Ledger Model**
- **Double SHA-256 Hashing**
- **Native AOT Smart Contracts**
- **Zero-Knowledge Confidential Amounts**
- **8 Decimal Places**
- **RocksDB Database**
- **Zero-Copy Serialization**
- **Hardware Exception Trapping**
- **Scheduled Block Reward Halving**
- **Open Blockchain Architecture**
